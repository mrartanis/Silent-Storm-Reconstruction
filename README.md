# Silent Storm Reconstruction

*Русский | [English](README.en.md)*

Реконструкция и модернизация движка **Silent Storm v1.2** на основе
[исходников Nival](https://github.com/nival/Silent-Storm), PDB версии v1.1
(RussianPatch1) и анализа релизной v1.2. Исходный код Silent Storm принадлежит
Nival. Цель проекта — сохранить поведение оригинальной игры и перенести движок
на современные 64-битные системы.

## Что сделано

Состояние на **23 октября 2026 года**:

- **64-битный движок и игра.** Полная игровая сборка x64, исправления зависимости
  от размера указателя, старого inline assembler и 32-битных структур данных.
  Переносимые форматы ресурсов, сохранений и сетевых состояний; чтение исходных
  игровых данных без предварительной конвертации.
- **Замена закрытых библиотек.** Используемые игрой возможности FMOD, Bink и
  LifeStudio/GDP реализованы открытым кодом: звук и музыка работают через
  FFmpeg/miniaudio, оригинальные ролики Bink декодируются FFmpeg, головы и
  анимация — собственной реализацией LifeStudio. Современная игровая сборка
  не требует оригинальных DLL или SDK этих библиотек.
- **Собственная лицевая анимация и FaceGen.** Загрузка исходных голов, мышц,
  костей, дерева макросов и последовательностей; мимика, речь, моргание,
  смешивание и генерация лиц. Нативная реализация сверяется с оригинальной
  x86-библиотекой по геометрии и анимации, включая корпус из **6 780
  последовательностей** для контрольной головы. Это проверенный корпус,
  а не гарантия попиксельного совпадения всех комбинаций FaceGen.
- **Кроссплатформенность.** SDL3 отвечает за окно, клавиатуру, мышь, текст,
  буфер обмена и системные события. Полная игра собирается для Windows x64,
  Linux x64 и Linux ARM64; переносимое ядро включает Lua, ИИ, бой, ресурсы,
  кампанию и сохранения.
- **Новый рендерер bgfx.** Прямой рендерер D3D9 и DirectInput заменены bgfx
  и SDL3. Windows использует backend Direct3D 11 через bgfx, Linux — Vulkan;
  зависимости игрового движка от старого DirectX runtime больше нет.
- **Современный экран и интерфейс.** Изменяемое окно, безрамочный полный экран,
  широкоформатные разрешения и Hor+ камера, адаптивные панели и масштаб UI,
  векторные шрифты FreeType/Liberation, ролики с сохранением пропорций.
  Исправлены инвентарь, окно персонажа, загрузочные экраны и выбор бойцов
  на широких экранах. Добавлены нативные системные курсоры.
- **Графика и производительность.** FXAA для 3D без размытия UI, анизотропная
  фильтрация, полное качество текстур при движении/отдалении камеры,
  улучшенные направленные тени со сглаженными краями. Исправлены мерцание
  освещения, переключение теней, подсветка объектов, первый кадр без фокуса
  и зависание при восстановлении окна. Оптимизированы преобразование и загрузка
  геометрии, GPU-буферы, объединение отрисовок и повторное использование
  framebuffer; добавлено профилирование кадров.
- **HD-текстуры.** Приняты **2 837 текстур** с увеличением в 4 раза по каждой
  стороне: мир и окружение, одежда, головы/волосы, экипировка, оружие, интерфейс
  и эффекты. Завершены доступные художественные карты мира, голов/волос,
  одежды и главного меню; технические маски сохраняют оригиналы. HD включён
  по умолчанию и переключается без перезапуска. Приоритет: моды → HD → оригинал.
  Пакет строится из PNG в Git, без генерации во время сборки или игры.
  Полного HD-покрытия всех ресурсов пока нет.
- **Сетевой тактический режим для двух игроков.** Прямое TCP/IPv4-подключение,
  выбор карты случайного столкновения, отдельные базы подготовки, отряды
  из 1–6 бойцов, уровни 1–20 и снабжение 1–14. Выбор персонажей, снаряжение,
  умения и готовность переносятся в бой. Синхронизируются движение/AP,
  стрельба, инвентарь, лечение, мины, гранаты, разрушения, прерывания и исход
  матча. Есть быстрый старт без подготовки и совместная игра Windows ↔ Linux.
  Оптимизированы репликация мира и обработка сетевых команд.
- **Исправления оригинальной логики.** Вход в миссии и случайные столкновения,
  улики и уведомления, диалоги, прицеливание, гранаты, панцеркляйны,
  скриптовые переходы, загрузка состояния и модификации базы ресурсов.
  Поддерживаются Unicode-имена профилей, слотов и пути сохранений.
- **Инструменты разработки.** CMake вместо старого решения Visual Studio,
  автоматические проверки ядра/рендерера/сети, сравнения x86 и x64,
  изолированные игровые прогоны, измерение FPS и упаковка Windows-сборки
  с данными, библиотеками, шрифтами и HD-паком.

## Поддерживаемые платформы

| Платформа | Статус и границы проверки |
| --- | --- |
| **Windows x64** | Основная игровая сборка; MSVC, SDL3, bgfx/D3D11. Проверяются графика, обычный ввод, звук/видео, сохранения и сеть. |
| **Linux x64** | Полная нативная игра; Clang, SDL3/X11, bgfx/Vulkan. Игровые и сетевые прогоны выполнены через Xvfb/lavapipe, включая Windows ↔ Linux. Физические GPU, звуковые устройства и HiDPI отдельно не проверены. |
| **Linux ARM64** | Полная AArch64-сборка; игра, графика и проверки ядра/сети запускались через QEMU и ARM64 lavapipe. Физическое ARM64-оборудование и сетевой графический клиент на нём не проверены. |
| **Windows x86** | Сохранён как диагностический эталон для сравнений с оригинальными 32-битными DLL; не основной вариант поставки. |
| **macOS** | Поддержка игры пока не заявляется: полноценная сборка и запуск на настоящем Mac не проверены. |

Полное прохождение кампании и полный поведенческий/визуальный паритет с релизной
Steam-версией ещё не подтверждены. Проверенные сценарии и оставшиеся отличия
описаны в отчётах ниже.

## Сборка

Движок выпускается отдельно от игровых данных и HD-пака. Workflow **Engine
release** собирает Windows x64 и Linux x64 по тегам `v*` и автоматически
публикует GitHub Release после успешных проверок. Порядок выпуска и пробного
запуска без публикации: [RELEASING.md](packaging/RELEASING.md).

### Зависимости

- **CMake 3.21+**, **Python 3.11+**, **Pillow**. NumPy нужен только для
  калибровки новых HD-текстур. Для существующего пакета достаточно Pillow.
- **SDL3 3.4.16**, пакет разработки для целевой архитектуры.
- **bgfx.cmake v1.161.9510-579** с закреплёнными деревьями bgfx/bimg/bx.
  Версии, хеши и устройство каталогов: [SDL3 + bgfx](probes/sdl3-bgfx/README.md).
  Зависимости располагаются вне этого репозитория; CMake не скачивает bgfx.
- **FFmpeg 8.1**, shared development package с заголовками и библиотеками
  `avformat`, `avcodec`, `avutil`, `swscale`, `swresample`;
  **miniaudio 0.11.25**, каталог с `miniaudio.h`.
- **FreeType 2.14.3** скачивается CMake с проверкой SHA-256. Для локальной
  копии исходников задайте `S2_FREETYPE_SOURCE_DIR`. Liberation Fonts 2.1.5
  уже находятся в `assets/fonts` и копируются в сборку.
- **Игровые данные Silent Storm v1.2** для запуска и ресурсных тестов.
  Используйте отдельную полную копию установки: `game.db`, `start.cfg`,
  `tree.mma`, `cfg`, `res`, `scripts`. В `S2_GAME_DIR` указывается эта копия;
  при сборке в неё также записывается `network-version.txt`.

HD собирается по умолчанию. Сам готовый пакет занимает около **9,2 ГБ**;
дополнительно нужно место для клона с PNG, зависимостей и сборки.
`-DS2_BUILD_HD_TEXTURES=OFF` отключает его сборку, но не удаляет существующий
пакет и не меняет настройку HD в игре.

### Windows x64

Нужны **Visual Studio 2022 или новее**, компонент «Разработка классических
приложений на C++», **MSVC v143** и **Windows SDK 10**. Сборки также проверялись
с VS 2026. Пример из корня репозитория в PowerShell; замените пути своими.
`bgfx.cmake` ниже — полное дерево с подкаталогами `bgfx`, `bimg`, `bx`.

```powershell
python -m venv build/hd-python
$hdPython = (Resolve-Path build/hd-python/Scripts/python.exe).Path
& $hdPython -m pip install Pillow
$deps = 'C:/s2-deps'

cmake -S . -B build -A x64 `
  "-DSDL3_DIR=$deps/SDL3-3.4.16/cmake" `
  "-DS2_BGFX_CMAKE_ROOT=$deps/bgfx.cmake" `
  "-DS2_BGFX_DIR=$deps/bgfx.cmake/bgfx" `
  "-DS2_BIMG_DIR=$deps/bgfx.cmake/bimg" `
  "-DS2_BX_DIR=$deps/bgfx.cmake/bx" `
  "-DS2_FFMPEG_ROOT=$deps/ffmpeg-8.1" `
  "-DS2_MINIAUDIO_INCLUDE_DIR=$deps/miniaudio-0.11.25" `
  "-DPython3_EXECUTABLE=$hdPython" `
  -DS2_GAME_DIR=C:/Games/SilentStorm-test `
  -DS2_BUILD_MEDIA_PROBE=ON -DS2_BUILD_MINIAUDIO_MUSIC_PROBE=ON `
  -DS2_ENABLE_NATIVE_MUSIC=ON -DS2_ENABLE_NATIVE_SFX=ON `
  -DS2_ENABLE_NATIVE_VIDEO=ON -DS2_BUILD_HD_TEXTURES=ON
cmake --build build --config Release --parallel
```

Результат — `build/Release/Game.exe`, DLL, `fonts`, `res-hd` и
`network-version.txt`. Все параметры native media в примере нужны для звука,
музыки и роликов: без них базовая x64-конфигурация использует медиа-заглушки.
`binkw32.dll` в современной сборке — наша библиотека совместимости, собранная
для x64, несмотря на историческое имя.

Для отладки соберите `RelWithDebInfo` и откройте `build/A5.sln`.
`build.bat` и `build-debug.bat` — обёртки для Release и RelWithDebInfo:
после полной конфигурации они используют сохранённые пути/параметры, а
переменная окружения `SDL3_DIR` должна быть задана. Для первого запуска одной
этой переменной недостаточно: обязательны также настройки bgfx и медиа выше.

Дополнительно собираются `DataImport`, `PkgBuilder`, `FontGen`, `TexConv` и
`TexMipStrip`. Старому инструменту `ShaderCompiler` требуется необязательный
DirectX SDK June 2010; без него инструмент пропускается. Рендерер игры
использует `shaderc` из bgfx и этого SDK не требует. `MapEdit`, `Scintilla`,
`OpenDynamix` и `LSConverter` сохранены в исходниках, но не включены в сборку.

### Linux x64

Проверенная конфигурация — **Clang 18**, Ninja, SDL3 с X11/XInput2,
Vulkan, FFmpeg, miniaudio, а также development-пакеты **libgsf-1, libpng,
zlib, X11/OpenGL** и `pkg-config`. XInput2 нужен для относительного ввода мыши.
Пути ниже указывают на предварительно подготовленные зависимости.

```sh
python3 -m venv build/hd-python
build/hd-python/bin/python -m pip install Pillow
deps=/opt/s2-deps

cmake -S . -B build-linux -G Ninja \
  -DCMAKE_BUILD_TYPE=RelWithDebInfo \
  -DCMAKE_C_COMPILER=clang-18 -DCMAKE_CXX_COMPILER=clang++-18 \
  -DS2_BUILD_GAME=ON \
  -DSDL3_DIR="$deps/sdl3/lib/cmake/SDL3" \
  -DS2_BGFX_CMAKE_ROOT="$deps/bgfx.cmake" \
  -DS2_BGFX_DIR="$deps/bgfx.cmake/bgfx" \
  -DS2_BIMG_DIR="$deps/bgfx.cmake/bimg" \
  -DS2_BX_DIR="$deps/bgfx.cmake/bx" \
  -DS2_BUILD_MEDIA_PROBE=ON -DS2_BUILD_MINIAUDIO_MUSIC_PROBE=ON \
  -DS2_FFMPEG_ROOT="$deps/ffmpeg-8.1" \
  -DS2_MINIAUDIO_INCLUDE_DIR="$deps/miniaudio-0.11.25" \
  -DPython3_EXECUTABLE="$PWD/build/hd-python/bin/python" \
  -DS2_GAME_DIR=/opt/games/SilentStorm-test \
  -DBGFX_WITH_WAYLAND=OFF -DS2_BUILD_HD_TEXTURES=ON
cmake --build build-linux --parallel
```

Результат — `build-linux/Game`, `fonts`, `res-hd`, `network-version.txt`.
На Linux native media включается игровой целью; отдельные Windows-флаги
`S2_ENABLE_NATIVE_*` не требуются. Без `S2_BUILD_GAME=ON` собираются переносимые
библиотеки и проверки, а не полная игра. Путь к shared-библиотекам SDL3/FFmpeg
должен быть доступен загрузчику, например через `LD_LIBRARY_PATH`.

### Linux ARM64

Для кросс-сборки используется
[LinuxArm64Clang.cmake](cmake/Toolchains/LinuxArm64Clang.cmake). Нужны Clang 18,
ARM64 GCC toolchain и заполненный ARM64 sysroot со всеми целевыми зависимостями,
включая SDL3, FFmpeg, libgsf, libpng и zlib. К Linux-параметрам выше добавьте
следующие параметры, убрав явные `CMAKE_C_COMPILER`/`CMAKE_CXX_COMPILER`:

```text
-DCMAKE_TOOLCHAIN_FILE=cmake/Toolchains/LinuxArm64Clang.cmake
-DS2_ARM64_SYSROOT=/opt/s2-arm64/sysroot
-DS2_ARM64_GCC_TOOLCHAIN=/usr
-DS2_BGFX_SHADERC=/opt/s2-host/bin/shaderc
```

Используйте отдельный каталог `build-arm64`, ARM64-пути `SDL3_DIR` и
`S2_FFMPEG_ROOT`, а также `PKG_CONFIG_SYSROOT_DIR`/`PKG_CONFIG_LIBDIR` из sysroot.
`shaderc` и Python выполняются на машине сборки. Для тестов через QEMU нужен
`CMAKE_CROSSCOMPILING_EMULATOR` с `qemu-aarch64-static -L <sysroot>`.
Полный пример настройки окружения:
[Build-Stage6-Linux.sh](diagnostics/Build-Stage6-Linux.sh); этот лабораторный
скрипт требует подготовленных каталогов зависимостей. Проверки и ограничения:
[BGFX-LINUX.md](diagnostics/BGFX-LINUX.md),
[MODERN-DISPLAY.md](diagnostics/MODERN-DISPLAY.md).

## Запуск и настройки

Перенесите исполняемый файл, **все библиотеки своей сборки**, `fonts`, весь
`res-hd` и `network-version.txt` в отдельную копию игровых данных.
Запускайте из этой копии: рабочий каталог должен содержать исходные данные
игры. На Linux также должны быть доступны соответствующие shared-библиотеки.

В графических настройках доступны разрешение, режим окна, анизотропия, FXAA,
VSync, FPS и HD. Кнопка **Display and interface** открывает масштаб UI и
векторные шрифты. Основные параметры пользовательского конфига:
`gfx_resolution=WxH`, `gfx_fullscreen=0/1`, `ui_scale=0/75/100/125/150/200`,
`ui_vector_fonts=0/1`. При смене режима есть подтверждение и автоматический
возврат. `S2_USER_DATA_DIR` позволяет выбрать отдельную папку профилей,
сохранений и настроек, в том числе для двух экземпляров игры.

Для сети откройте **«Сетевая игра»**: хост создаёт матч, второй игрок вводит
IPv4 и порт (по умолчанию TCP **7780**, локально — `127.0.0.1`). Нужны
совместимые сборки из одинаковых исходников, одинаковые данные и активные моды;
HD на совместимость не влияет. TCP-порт хоста должен быть доступен клиенту.
Лобби в интернете, автоматическая передача ресурсов, реконнект, сетевые
сохранения, античит и отдельный режим против ИИ пока не реализованы.
Подробности: [NETWORK_MODE.md](diagnostics/NETWORK_MODE.md).

## Проверки и упаковка

После сборки всех целей:

```powershell
ctest --test-dir build -C Release --output-on-failure
& $hdPython assets/terrain-hd/validate_pack.py --pack build/Release/res-hd
```

На Linux используйте `ctest --test-dir build-linux --output-on-failure`.
Ресурсные проверки регистрируются при заданном `S2_GAME_DIR` с нужными данными;
графические проверки требуют дисплея и рабочего графического backend.
Расширенные сценарии могут выполняться долго. Исторические результаты и
известные ограничения приведены в отчётах ниже.

Самодостаточный Windows x64 архив из готовой сборки:

```powershell
python diagnostics/Package-Game.py --game-data C:/Games/SilentStorm-test --build build/Release --crt-runtime "C:/Path/To/Microsoft.VC143.CRT" --output SilentStorm-Windows-x64.7z
```

Нужны x64 Visual C++ Runtime из Visual Studio и 7-Zip для `.7z`;
`.zip` выбирает ZIP. Упаковщик добавляет игровые данные, DLL, шрифты,
HD, `Play.cmd`, инструкцию и контрольную сумму, проверяет пакет и архив.
HD включён по умолчанию; `--no-hd-textures` отключает его явно.
У `.7z` используется LZMA2 со словарём 512 МиБ, столько же памяти потребуется
для распаковки. Готовая распакованная копия сохраняется рядом с архивом.
