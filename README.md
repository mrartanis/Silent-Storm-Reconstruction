# Разработка переехала в Silent Storm Remaster

Актуальный репозиторий: **[mrartanis/silent-storm-remaster](https://github.com/mrartanis/silent-storm-remaster)**.

С 24 октября 2026 года разработка, новые изменения и инструкции по сборке находятся там.
В новый репозиторий перенесена очищенная история проекта; исходные HD-текстуры и
готовый HD-пак хранятся в Git LFS.

Этот форк сохранён как исторический архив. Уже опубликованные релизы доступны
по прежним адресам и не изменяются:

- [Движок v0.1](https://github.com/mrartanis/Silent-Storm-Reconstruction/releases/tag/v0.1)
- [Готовый HD-пак hd-v0.1](https://github.com/mrartanis/Silent-Storm-Reconstruction/releases/tag/hd-v0.1)

Исходный код Silent Storm принадлежит Nival. Предыдущая история реконструкции
и материалы проекта остаются в этом репозитории.
