# Промпт для продолжения HD-текстур

Продолжи HD-текстуры Silent Storm в репозитории `G:\SS\Silent-Storm-Reconstruction`, ветка `develop`. Сначала прочитай применимые AGENTS.md, `assets/terrain-hd/README.md`, `sources.json`, `expanded/queue.json`, `expanded/coverage.json`, `expanded/rgb565-followup.json` и `expanded/full-texture-inventory.json`. Последний файл содержит 5 801 запись текстур БД в UTF-8. Текущие 1 952 принятые HD-текстуры сохраняй: 178 ландшафта, 29 деревьев и 1 745 зданий/окружения. Все 2 339 записей прежней очереди получили статус; это ещё не вся БД игры.

Изображения распределяются как `assets/terrain-hd/archives/*.zip` в GitHub Release: этот публичный форк не может загружать новые LFS-объекты. После клонирования выполни `python assets/terrain-hd/archive_assets.py unpack --download --build --validate`. Нужны Python 3.11+, Pillow и NumPy. Индекс содержит закреплённые URL и SHA-256 каждого ZIP. Архивы восстанавливают исходные, сырые AI, нормализованные и откалиброванные PNG по проверяемым хешам. Готовые `res-hd/*.res` собираются офлайн и не хранятся повторно в Git. Исторические ресурсы `G:\SS\Silent-Storm\Complete\Textures` и baseline `G:\SS\lab\baseline\res` читай без изменений. На другой машине сначала найди эти источники; локальные файлы в lab не считать частью клона.

Сначала доделай десять цветовых RGB565-текстур, ошибочно исключённых прежним фильтром: 5076 — кора ствола; 5168/5169 и 7581–7586 — часы и повреждённые варианты; 6997 — медицинская кровать. Все десять исторических изображений пиксельно совпадают с релизными, что подтверждено отдельной проверкой. Поддержи native MMP format 8 (`CF_R5G6B5`) при декодировании, проверь исходники самостоятельно и добавь их в очередь. Нельзя автоматически исключать DB Format=565 как нормали: это обычный цветовой формат. После добавления обнови реальные числа покрытия и прежние заявления о полноте.

Затем создай отдельные очереди персонажей/одежды, экипировки, оружия, голов/лиц, интерфейса и эффектов. Сначала сверь использование ресурсов, типы, размеры и исходники, отдели подтверждённые Bump/normal/служебные карты от художественных изображений. Предварительные числа записей без Type=Bump: персонажи 389, экипировка 317, оружие 229, головы и LSHead 194, Interface v5 — 778, эффекты вне прежнего пакета — 229. Это не готовая очередь генерации: среди них есть технические ресурсы, дубли и возможные неиспользуемые изображения. Семь записей экипировки тоже имеют Format=565. Другие группы БД дополнительно проверь по полному инвентарю, не объявляй всю игру законченной по одному списку путей.

Апскейл выполняй встроенным imagegen по отдельным исходным текстурам. Сохраняй UV-раскладку, размер рисунка и повторов, число досок/панелей, исходные материалы, повреждения, отверстия и силуэты. Не превращай траву в крупные листья/новые растения, дерево в металл, плоские надписи в объёмные таблички; не добавляй логотипы, символы, болты, сцены и объекты. Для лиц сохраняй персонажа и стиль. Каждое оригинальное изображение осмотри до генерации, каждое нормализованное изображение проверь приватно. Чёрные поля, добавленные генератором, исправляй только после подтверждения исходного UV-положения. Сохраняй сырой результат и точный промпт сразу по завершении каждого задания.

Яркость выравнивай программно через `match_brightness.py`, без повторной генерации ради яркости. Сохраняй исходную альфу в native pack; используй существующее заполнение RGB под силуэтом и очистку мусора под прозрачностью. Не меняй топологию спрайтов и масштаб элементов. Для UI отдельно проверь связь физического размера текстуры и логических размеров элементов, координат атласа, читаемость текста, курсоры и шрифты; существующие векторные шрифты не превращай в растровый апскейл. Повторяющиеся исходники переиспользуй только после точной сверки RGBA, размеров, типа альфы и atlas layout (`reuse_generated.py`).

Разрешены сабагенты, по одному на независимый пакет. Они могут готовить изображения, результаты проверки и отдельные списки заданий. Общие `sources.json`, очередь, числовую калибровку, архивный индекс и native-сборку меняет только координатор; импорт, калибровку и валидацию выполняй последовательно. Не запускай всю следующую очередь повторно, если часть уже принята; не импортируй старые целые пакеты поверх проверенных исправлений.

Не показывай пользователю сравнения и не создавай новые HTML-сравнения. Переключатель «HD текстуры» уже включён по умолчанию: выключение полностью игнорирует HD-слой и возвращает исходные размеры без перезапуска. Сохрани это поведение, приоритет моды → HD → база и отсутствие влияния визуального пакета на сетевую совместимость.

48 отсутствующих исторических исходников, релизное несовпадение 5864 и восемь ID с недоступной генерацией (5930, 5932, 6732, 7110, 7112, 7113, 7117, 7118) пока используют оригиналы. Причины находятся в coverage и generation-unavailable. Не обходи отказы сервиса и не подменяй исходное содержание без отдельного разрешения пользователя. Пользователь уже разрешил замену обложек только на шести книжных текстурах 3795, 3796, 3797, 3953, 6206, 6207; они завершены, согласованы между целыми/повреждёнными версиями и откалиброваны.

После каждого принятого пакета выполни импорт, проверку всех новых изображений, калибровку и сборку. `validate_pack.py` должен проверить весь текущий native pack, включая алиасы, mip-цепочки, альфу и яркость. Обнови coverage, документацию и `archive_assets.py pack`; команда остановится, если прежние PNG ещё не распакованы. Загрузи изменённые ZIP в новый GitHub Release, внеси новые `download_url` в индекс, сохрани URL неизменённых архивов. После существенного расширения проверь HD → оригиналы → HD через реальное меню в изолированном запуске игры, сохрани кадры/отчёт и выйди штатно (`quit`); пользовательские процессы не закрывай. Последняя проверка Windows/D3D11 на 1 952 текстурах при 2560×1440 прошла: 11 → 0 → 11 HD-патчей, примерно 60 FPS, штатный выход. Это подтверждает ту сцену, а не все модели во всех миссиях. Коммить и пушь законченные проверенные пакеты с честным описанием оставшегося покрытия.
