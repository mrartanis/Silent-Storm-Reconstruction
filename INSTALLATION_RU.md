# Установка Silent Storm Reconstruction v0.1

Готовый движок выпускается для Windows 10/11 x64 и Linux x86_64. Для игры нужны данные **оригинальной Silent Storm версии 1.2** из вашей установленной копии. В Steam Gold Edition есть также Sentinels: для этой инструкции выбирайте основную Silent Storm.

## Что скачать

1. Откройте [релиз движка v0.1](https://github.com/mrartanis/Silent-Storm-Reconstruction/releases/tag/v0.1).
   - Windows: `silent-storm-engine-v0.1-windows-x64.zip`.
   - Linux: `silent-storm-engine-v0.1-linux-x64.tar.gz`.
2. По желанию откройте [отдельный релиз HD-пака hd-v0.1](https://github.com/mrartanis/Silent-Storm-Reconstruction/releases/tag/hd-v0.1) и скачайте **все** файлы `silent-storm-hd-v0.1-partNN.zip`.

Архивы `Source code` для установки не нужны. Старый релиз `hd-textures-20261007-1952` содержит исходные материалы; для игры используйте готовый `hd-v0.1`. Python, компилятор и сборка проекта не требуются. HD-пак одинаковый для обеих платформ. Он содержит 2 837 текстур с четырёхкратным увеличением по каждой стороне; остальные ресурсы игра берёт из оригинала.

## Подготовить данные Steam

1. В Steam откройте свойства Silent Storm → установленные файлы → обзор файлов. Найдите папку основной игры, в которой лежат `game.db`, `start.cfg`, `tree.mma`, `cfg`, `res` и `scripts`. Например, `…/steamapps/common/Silent Storm`.
2. Создайте отдельную пустую папку, например `C:\Games\SilentStorm-Reconstruction` на Windows или `~/Games/SilentStorm-Reconstruction` на Linux.
3. Скопируйте туда `game.db`, `start.cfg`, `tree.mma` и папки `cfg`, `res`, `scripts` **целиком**. При желании скопируйте `Docs`.

В `res` нужны не только архивы `.res`, но и отдельные файлы и подпапки. Старые EXE и DLL из Steam копировать не нужно. Оригинальную установку Steam можно оставить как есть. На Linux нужны те же данные Windows-версии игры: их можно перенести из собственной установленной копии.

## Установить движок

Распакуйте архив движка. Внутри находится папка `silent-storm-engine-v0.1-…-x64`; перенесите **её содержимое** в подготовленную папку игры. `Game.exe` или `Game` должен оказаться рядом с `game.db`, а не ещё на один уровень глубже. Сохраните все поставляемые библиотеки, шрифты и `network-version.txt`.

### Windows

Запустите `Play.cmd` из новой папки. Он выбирает правильную рабочую папку и запускает `Game.exe`. Не запускайте старый EXE из Steam. Библиотеки среды MSVC уже включены в архив.

### Linux

Сборка рассчитана на Ubuntu 24.04 x86_64 или совместимую систему с glibc 2.39+. SDL3 и FFmpeg поставляются в папке `lib`; системные библиотеки и драйвер видеокарты устанавливаются средствами дистрибутива. Для Ubuntu 24.04:

```sh
sudo apt install libgsf-1-114 libpng16-16t64 zlib1g libx11-6 libxi6 libgl1 libvulkan1
```

Нужен установленный Vulkan-драйвер для вашей видеокарты. После переноса содержимого архива откройте терминал в папке игры:

```sh
chmod +x Play.sh Game
./Play.sh
```

`Play.sh` подключает поставляемые библиотеки из `lib`. Движок запускается как обычная программа Linux.

## Установить HD-пак

Игра работает и без HD. Для HD выделите около 10 ГБ под распакованный `res-hd`; дополнительно нужно место под скачанные ZIP-файлы и оригинальные данные. Около 20 ГБ свободного места удобно для всей установки.

Распакуйте **каждый** `silent-storm-hd-v0.1-partNN.zip` в одну и ту же папку игры. Это самостоятельные ZIP-архивы: открывайте каждый обычным архиватором. Объединять файлы или переименовывать расширения не нужно. При запросе разрешите объединение папок `res-hd`.

В итоге структура должна выглядеть так:

```text
SilentStorm-Reconstruction/
  Game.exe + Play.cmd             # Windows
  Game + Play.sh + lib/           # Linux
  fonts/
  network-version.txt
  game.db
  start.cfg
  tree.mma
  cfg/
  res/
  scripts/
  res-hd/                        # если установлен HD
    manifest.json
    Textures.res
    Textures-0001.res
    …
```

HD включён по умолчанию. Переключатель **«HD текстуры»** в настройках графики позволяет менять режим во время игры. Если HD-замены для ресурса нет, используется оригинал. HD не меняет сетевую совместимость.

Для проверки загрузки сравните SHA-256 файлов с `SHA256SUMS` соответствующего релиза. В Windows хеш показывает `Get-FileHash имя-архива -Algorithm SHA256`; в Linux, находясь в папке с архивами и `SHA256SUMS`, выполните `sha256sum --check SHA256SUMS`.

## Сохранения, сеть и обновление

Сохранения и пользовательские настройки хранятся отдельно от установки:

- Windows: `%LOCALAPPDATA%\Silent Storm Reconstruction`.
- Linux: `$XDG_DATA_HOME/silent-storm-reconstruction`, обычно `~/.local/share/silent-storm-reconstruction`.

Если ранее задана переменная `S2_USER_DATA_DIR`, используется выбранная в ней папка.

Для сетевой игры оставьте поставляемый `network-version.txt` рядом с `game.db`. Его не нужно генерировать или редактировать. В v0.1 версия совместимости — `1`, семейство данных — `silent-storm-1.2`. У участников должны быть совместимые версии движка и игровых данных; для первого подключения используйте одинаковый релиз без модов. Разработчики меняют версию совместимости вручную при несовместимых изменениях.

При обновлении движка перенесите содержимое нового архива поверх файлов движка, включая его `network-version.txt`. Данные игры, HD и пользовательские сохранения можно сохранить. При замене HD сначала уберите старую папку `res-hd` из папки игры, затем распакуйте все части нового пака: это исключает оставшиеся архивы от предыдущей версии.

## Если не запускается

- Не найден `game.db`: проверьте структуру папок выше и запускайте через `Play.cmd` / `Play.sh`.
- Не хватает DLL: распакуйте движок целиком; не смешивайте его библиотеки со старой установкой Steam.
- Linux сообщает об отсутствующей `.so`: запускайте через `Play.sh`, проверьте папку `lib` и установленные системные зависимости.
- HD не появился или часть текстур осталась оригинальной: проверьте, что извлечены все части в `res-hd` рядом с игрой и включён переключатель HD. Пак заменяет только перечисленные в его манифесте 2 837 текстур.
- Ошибка `network-version.txt`: восстановите файл из архива своего движка и проверьте совместимость релизов участников.
