# Игровые raw-типы сериализатора: аудит этапа 2

В `CStructureSaver` переносимые кодеки уже пишут известные игровые поля
без зависимости от host-выравнивания. Для оставшихся `DataScalarChunk` и
`DataArrayChunk` с `kPortable=false` добавлен диагностический счётчик
реально прочитанных типов, их `sizeof(T)`, tag и ID внешнего объекта.
Он работает только при `g_bWireAudit` (загрузка через `-loadslot`),
дописывает строки `RAW-TYPE` и `RAW-TYPE-AUDIT-DONE` в `_wireaudit.log`.
Обычный игровой запуск не пишет этот журнал. Этот счётчик не охватывает
ручной `AddRawData(void*)`, поэтому не является полным статическим аудитом.

Чистый x64-архив с native media из `7843985`:
`C:\SS-lab\builds\stage2-raw-audit-20260925-01`. В изолированном запуске
`C:\SS-lab\runs\stage2-raw-audit-clean-01` установлен `-loadslot` и
скопирован без изменения старый слот `stational weapons`. Загрузка
достигла `LOAD-DESERIALIZE-COMPLETE` и `LOAD-SLOT-DONE`, затем `quit`
завершил Game/CDB без crash dump. Аудит охватил и подгрузку ресурсов при
старте, и миссионный сейв: поэтому повторяющиеся блоки журнала — разные
проходы сериализатора, а не кратность полей одного save-файла.

В этом сценарии обнаружено 54 различных имени raw-типа. Среди значимых
для игровой логики: `SRandomSeed` (9 путей типа/поля), `NAI::SPathPlace`,
`NAI::SJunction`, `NAI::SZone`, `NRPG::SCritical`, `NWorld::SObjectPlace`;
есть также геометрия, анимация, шрифты и UI. Число 54 **не** означает,
что все эти типы уже перенесены, и не доказывает полноту для других
миссий или всех оригинальных ресурсов. Следующий игровой перенос —
`SRandomSeed`: одно 32-битное слово, используемое в детерминированных
правилах и сохранениях.

Воспроизведение на этом стенде: собрать чистый архив через `Build-Lab.ps1`,
создать `New-LabRun.ps1`, скопировать слот в
`<run>/user-data/save/default/stational weapons`, записать имя в
`<run>/game/_loadslot.txt`, запустить `Start-LabRun.ps1 -GameArguments
'-windowed -800 -harness -loadslot'`. Проверить `_saveload.log`,
`_wireaudit.log` и отсутствие `evidence/crash.dmp`. Для новых типов
повторять аудит на иных миссиях и игровых действиях; не переносить
редакторские типы только потому, что они есть в исходниках.

Если не хватает места для повторного копирования 2,45 ГБ `res`,
`New-LabRun.ps1 -LinkResources` исключает `res` из копирования и
создаёт в новом LabRun NTFS-junction на проверенный
`<LabRoot>/baseline/res`. Архив EXE, `game.db`, конфиг, журналы и
`user-data` остаются отдельными. Режим годится только для чтения
неизменяемых ресурсов: не применять его к сценариям, которые меняют
ресурсы или проверяют изоляцию модов. `evidence/run.json` записывает
`LinkedResources` и точный `ResourceSource`.
