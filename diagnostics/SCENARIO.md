# Сценарий S1 (проверяется реальным вводом)

Исходная точка: новый каталог из неизменяемого baseline, новый профиль default без сохранений, Steam Russian build 122676; один архив EXE/PDB. Команда: Game.exe -windowed -800 -harness. AI включён, игровые параметры не меняются. Случайность игры не фиксирована: исходный WinMain вызывает srand(GetTickCount()); одинаковая исходная точка не означает детерминированные попадания.

1. Запуск под CDB. Пропустить заставки клавиатурой; получить главное меню.
2. Войти в обучение (если доступно) или создать одинакового стандартного персонажа новой кампании; записать точный выбранный путь и миссию после первого просмотра UI.
3. В миссии выбрать бойца мышью и переместить на соседнюю доступную точку. Подтвердить смену положения скриншотом.
4. I: открыть инвентарь, осмотреть экипировку, закрыть I/Escape.
5. Выбрать оружие и доступную цель; совершить атаку штатным UI. Записать цель и результат, не требовать одинакового попадания.
6. Enter: включить пошаговый режим при необходимости и передать ход. Проверить возврат управления после AI.
7. Сохранить через меню в новый слот LAB_S1; загрузить этот слот; проверить положение и инвентарь.
8. Выйти штатно и сохранить логи/скриншоты/сохранение/дампы/метаданные.

Повторить 3 раза, каждый раз в новом каталоге от одинакового baseline. Нельзя пропускать первый блокер: если запуск/миссия падает или зависает, остальные пункты отмечаются «не достигнуты».

Зависание: после 30 секунд без прогресса и реакции снять два дампа с интервалом 5–10 секунд, записать CPU/состояние окна. Загрузка до 120 секунд допустима; зависание не выводится только из свойства Responding. После фиксации завершить только тестовый процесс. Нестабильные сбои помечать по частоте из 3 попыток.

Результаты 2026-09-18: attempt-01, attempt-02, attempt-03 — запуск и главное меню доступны, шаг 2 заблокирован несовместимостью ввода. Два клика по «Учебная миссия» и F7 не вызывают перехода. Шаги 3–7 не достигнуты. Это три документированные попытки, а не три успешных прохождения. Полный сценарий остаётся процедурой для проверки после устранения блокера; конкретная цель атаки ещё не выбрана.

Каждый прогон отдельно загружал template 3589, героя 730, Day через существующий harness до приветственной подсказки. Этот подшаг не засчитывается за реальный UI и не доказывает идентичность всех параметров штатного старта обучения. Материалы находятся в G:\SS\lab\runs\attempt-0{1,2,3}\evidence; REPRO.md фиксирует порядок и ограничения. Исходного сохранения нет, используется новая копия baseline. Выход выполнен командой harness quit; в первых двух прогонах затем закрыт отладчик, остановившийся на финальном завершении процесса.
