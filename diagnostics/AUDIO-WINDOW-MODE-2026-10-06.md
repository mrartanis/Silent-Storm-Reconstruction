# Громкость и полноэкранное окно без рамки

Дата: 2026-10-06. Продолжение NETWORK-BUGS-2026-10-05.md по отдельной просьбе
пользователя. Зависание после сворачивания и долгий первый запуск остаются
отложенными. Игровые ресурсы не изменялись.

## Причина и исправление громкости

На предыдущей сборке r3 обычный клик по плюсу музыки менял положение ползунка
(.75 → .76), но оставлял `sound_musicvolume` равным .75 после штатного выхода.
Поставляемый экран не содержит кнопки «Применить», а обработчик применял
громкость только по её событию. Исправлен общий экран звука, используемый
главным и игровым меню: ползунки и сброс сразу обновляют микшер и сохраняют
пользовательские настройки. Уже играющие эффекты получают новый общий gain.

Музыкальные потоки теперь создаются и при нулевой громкости, чтобы музыку
можно было включить без смены сцены. Обновления затухания ограничены текущей
общей громкостью; восстановление из нуля использует новое значение.

## Режим окна

«Настройки → Видео → Режим окна»: Окно / Полный экран / Без рамки.
Старые значения `gfx_fullscreen` 0/1 сохранены; 2 обозначает безрамочный режим.
SDL desktop fullscreen использует текущий монитор и его разрешение без
назначения эксклюзивного видеорежима. Рендер получает фактический размер.
Возврат в окно использует сохранённый оконный размер. Подтверждение сохраняет
выбор, прежний механизм 15-секундного отката остаётся активен.

В новой поставке Play.cmd запускает игру без принудительного `-windowed`,
поэтому сохранённый режим восстанавливается. Первый запуск настроен оконным.
Также доступен параметр `-borderless`.
