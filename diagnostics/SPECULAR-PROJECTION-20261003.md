# Мерцание бликов на машине при движении камеры

Последний пользовательский quicksave от 2026-10-03 19:15 скопирован в
изолированный слот `car_glints_quick_20261003`. Оригинал не изменяется.
Исследование и кадры: `G:/SS/lab/runs/shadow-disappearance-20261003-01/evidence`.

## Причина и исправление

Варианты PS 1.4 `psFullPerPixelSpecular` и `psFullPerPixelTexSpecular`
читали экранную маску солнечной тени без деления координат на W.
NH и diffuse проходы использовали правильную проекцию. Из-за этого
при смене камеры блик умножался на маску из другого участка экрана
и пропадал сразу с большой части капота и крыла.

В действующих shader tokens чтение маски изменено на `texld ... tN_dw.xyww`:
stage 2 для цветного материала, stage 3 для текстурного. Переводчик shader
tokens остаётся общим; зеркало, точечные источники, depth test и сила блика
не изменены.

Проверка `precise SV_POSITION` не устранила скачки и отменена.
На одинаковой позиции камеры движущийся и неподвижный кадры совпадали:
это была ошибка выборки маски при изменении ракурса, а не отдельный режим
восстановления освещения при движении.

## Регрессии

- `BgfxRendererTests --specular-projection`: реальные vertex/pixel shaders
  обоих материалов, perspective с переменным W, три расстояния и три
  смещения. 165888 пикселей совпадают с экранной маской при `DEPTH_EQUAL`.
  С прежними tokens тест падает с кодом 151: ожидает 200, получает 48.
  Проверка добавлена в CTest как `SpecularProjectionRuntimeTests`.
- `SpecularContinuity.py`: 17 шагов камеры по 0.1, world clocks остановлены;
  каждый кадр снят с бликом и без него. На старой сборке соседние шаги дают
  скачок суммы яркости блика до 7.57 раза. После исправления максимальное
  отношение 1.044; блик сохраняется на всех позициях. Проверка также требует
  >5000 пикселей блика на каждом шаге, чтобы отключение эффекта не прошло тест.
- Renderer/default, `--shadow-pcf`, `--graphics` прошли.
- `LightingMotion` на `shadows2`: три кадра при непрерывном движении,
  остановка, возврат после большого сдвига, этажей и зума прошли.
  Проверяются только относящиеся к этой части плана observations;
  дополнительный замер машины имеет отдельный `perfmotionstatus`.
- Отдельные одинаковые старты car fixture при 2560x1440 и постоянном движении:
  117.76 FPS до и 117.76 после, по 240 кадров. Замер после загрузки другой
  карты внутри той же сессии не используется для сравнения: отличались
  состояние анимаций и количество CPU combine operations.

Генерация и проверка кадров:

```powershell
python diagnostics/SpecularContinuity.py plan <plan.json> --tag car
python diagnostics/ProfileFrames.py <isolated-run> <plan.json>
python diagnostics/SpecularContinuity.py check <isolated-run>/evidence --tag car
```

Для `check` нужны NumPy и Pillow. Требуются именно указанная car fixture
и разрешение 2560x1440; слот можно назвать иначе через `--save`.
Все тестовые игры завершаются штатным `quit`.

Обычная сборка для ручной проверки:
`G:/SS/lab/runs/specular-fixed-20261003-01/Play.cmd`.
Сейвы берутся из прежнего пользовательского каталога.
